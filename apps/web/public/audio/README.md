# Voice clips

Generated by `scripts/gen-voice.ts` with ElevenLabs and committed as static
files, so the patient flow never waits on a live API call.

    ELEVENLABS_API_KEY=... npm run gen-voice --workspace apps/web

Five clips per language, named after the capture step: `welcome`,
`write_code`, `frame`, `review`, `sent`.

No clip says the challenge code out loud — the code is different per link, so
every clip points at the code shown on screen. The same text is always on
screen too, which is the fallback if ElevenLabs gets cut (see the PRD cut
order).
